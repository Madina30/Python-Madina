# Practice 09 - Game Development with Pygame

## Introduction

In this practice, I learned how to create simple games using Python and Pygame.

I completed three tasks. I worked with graphics, keyboard controls, animations and music playback.

## Task 1 - Mickey's Clock

I created a clock that shows the current minutes and seconds. I used two cartoon glove hands that rotate according to the system time.

## Task 2 - Music Player

I created a music player that can play songs from a playlist. I added keyboard controls to play, stop and change songs.

## Task 3 - Moving Ball Game

I created a simple game with a red ball on a white background. The ball moves using the arrow keys and cannot go outside the screen.
